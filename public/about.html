🔌 在 OpenClaw 注册 AgentMoss

推荐使用一键配置脚本 setup-agentmoss.sh，自动将 AgentMoss 安全引擎注册到 OpenClaw 插件体系中，无需手动编辑 JSON。

🚀 方式一：一键配置脚本（推荐）

下载并运行脚本，自动修改 ~/.openclaw/openclaw.json，完成注册：

bash# 下载并执行一键配置脚本（默认端口 19877） curl -fsSL https://agentmosi.github.io/setup-agentmoss.sh | bash # 可选参数：自定义端口 / 监控地址 / 纯审计模式 / 预览 curl -fsSL https://agentmosi.github.io/setup-agentmoss.sh | bash -s -- -p 19876 curl -fsSL https://agentmosi.github.io/setup-agentmoss.sh | bash -s -- --audit-only curl -fsSL https://agentmosi.github.io/setup-agentmoss.sh | bash -s -- --dry-run
-p, --port指定 AgentMoss 端口（默认 19877）
-u, --url自定义完整 monitorUrl
--fail-open监控不可用时放行（默认 fail-closed 阻断）
--audit-only仅审计模式，不阻断实际调用
--dry-run预览变更，不修改文件
📝 方式二：手动编辑 JSON（备选）

在 OpenClaw 配置文件 openclaw.json 的 plugins 段中添加以下内容：

openclaw.json{ "plugins": { "entries": { "agentmoss": { "enabled": true, // ⬇️ AgentMoss 安全监测服务地址 "config": { "monitorUrl": "http://127.0.0.1:19877", "timeoutMs": 80, // 实时检查超时，建议 ≤ 100ms "failClosedOnError": true, // 监控不可用时阻断工具调用 "observeHooks": true, // 采集模型输入输出、工具结果等观察事件 "auditOnly": false // 关闭纯审计模式，真正执行阻断 } } }, "allow": ["agentmoss", /* 其他插件 ... */] } }

💡 注册后 OpenClaw 会在 before_tool_call 钩子将工具调用参数发送给 AgentMoss 安全引擎；引擎依据安全规则库执行注入检测、密钥匹配、路径扫描等策略，返回 allow / block / require_approval 三级裁决；高风险操作被实时阻断并触发告警。
